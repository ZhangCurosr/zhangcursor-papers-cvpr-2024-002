# 论文速读：PaReNeRF: Toward Fast Large-scale Dynamic NeRF with Patch-based Reference

## 一句话总结
本文提出 PaReNeRF，在 SUDS 基线上引入基于光流的先验信息搜索和轻量级参考解码器，替代随机光线采样为 patch 采样并采用低分辨率渲染+上采样策略，在 KITTI/VKITTI2 数据集上实现训练时间减少 60%、推理时间减少 87%、PSNR 提升 13% 的同时保持高质量重建。

## 研究问题与动机
- **大规模动态场景重建速度慢**：现有 SOTA 方法（如 SUDS、Mars）对约 9 秒视频的训练需 2 天以上，推理也耗时超过 12 秒/帧，无法满足模拟器等实时应用需求。
- **低分辨率渲染虽快但牺牲质量**：UniSim 等通过低分辨率特征图+CNN 上采样加速，但重构精度明显下降；仅做 patch 采样可提速训练却无法改善推理速度。
- **稀疏轨迹下先验信息利用不足**：自动驾驶采集数据具有稀疏性和单轨迹特点，已知视角间存在可互补信息，但现有稀疏输入 NeRF 方法仅适用于小尺度静态场景，难以扩展到动态大规模场景。
- **参考搜索开销大**：在全图中搜索相似区域耗时高，如何在训练阶段快速定位参考先验信息是需要解决的关键工程问题。

## 核心贡献（创新点）
- **光流+结构相似性（SSIM）先验搜索方法**：在训练阶段利用 2D 光流预测缩小参考区域搜索范围，再通过滑动 patch 计算 SSIM 找到最优参考 patch，在推理阶段对全图计算 SSIM 选取最优参考图；区别于 NeRF-SR 仅依赖深度图做静态场景搜索，本方法适配动态场景。
- **Patch 采样替代随机光线采样 + 低分辨率渲染+CNN 上采样**：将每次数据读取从 N 次降至 N/(h×w) 次，大幅减少训练数据加载开销；与 Unisim 纯 CNN 上采样方案不同，本方法进一步引入参考解码器补偿质量损失。
- **轻量化参考解码器（Reference Decoder）**：基于 CARN 设计，融合来自已知视角的高分辨率参考图像特征与辐射场输出的低分辨率特征图，联合解码上采样为最终高分辨率图像；与 pixelNeRF/MVSNeRF 仅提取特征体积进行插值的做法不同，本方法面向大规模动态场景设计了专门的搜索与融合机制。

## 方法详解
**基线：SUDS**。SUDS 将场景分解为三个分支：静态分支（静态地形，hash table 映射到视图相关颜色 c_s 和视图无关密度 σ_s）、动态分支（处理瞬态和真正动态物体，σ_d 和 c_d 均依赖时间）、远场分支（环境贴图）；联合优化时最小化重建损失、形变损失、光流损失、动静因子分解损失和阴影损失。

**（1）Patch 采样辐射场**：将随机光线采样改为 patch 采样。设 patch 大小为 h×w，原来每批次 N 条光线需加载 N 次数据，改为只需加载 N/(h×w) 次。同时输出改为低分辨率特征图 F ∈ R^{H_f×W_f×N_f}（尺寸 414×125），而非原 SUDS 的 HR RGB（1242×375），减少射线查询次数。

**（2）先验信息搜索模块**：
- **训练阶段**：对随机采样 patch P ∈ R^{h×w×3}，取其像素坐标范围 (i,j) ∈ [(si,sj),(si+h,sj+w)]，根据已知 2D 光流 fl_{ij} 计算前后视图中相似区域 Ref_f 和 Ref_b（由 min/max 坐标变换确定）。在两个区域内逐像素滑动 patch p，计算其与 P 的 SSIM s，取最大 SSIM 对应的 patch 作为参考 patch RP。
- **推理阶段**：对新视图体渲染特征图 F 与所有已知视图 RGB 图 Î_m 计算 SSIM，取最高者作为参考图 RI。

**（3）参考解码器结构 rf**：函数形式 rf: (F ∈ R^{H_f×W_f×N_f}, R ∈ R^{H×W×3}) → I ∈ R^{H×W×3}。包含四个模块：① 参考图 RI 的特征编码器提取隐藏特征；② CARN 级联残差网络编码器对低分辨率特征图 F 和融合特征分别编码，多层局部/全局级联模块整合多尺度信息；③ 3×1 卷积层+PixelShuffle 上采样模块将 LR 特征图上采样 3 倍；④ 特征解码器将最终特征图渲染为 RGB 图像。

**（4）优化**：沿用 SUDS 全部损失函数，仅将 L2 光度损失 L_c(r)=||C(r)-Ĉ(r)||² 中的 C(r) 从 SUDS 辐射场直接输出的 RGB 替换为参考解码器重建后的图像；损失以 patch-wise 方式计算。训练 125K 轮，每批次 4096 条光线（16 个 16×16 patch），Adam 优化器学习率从 5×10⁻³ 衰减至 5×10⁻⁴。

## 实验与结果
**数据集**：KITTI [12] 和 Virtual KITTI-2 (VKITTI2) [2]，训练序列最多 90 帧（9 秒），图像尺寸 1242×375，双视角。NVS 任务使用 75%/50%/25% 三种 train/test 分割（每隔 4/2/4 帧测试）。

**评估指标**：PSNR、SSIM、LPIPS，以及训练/推理时间。

**KITTI 图像重建**（Table 1）：PaReNeRF 在全部指标上最优，PSNR=32.642（SUDS 为 28.31，↑13%），SSIM=0.933（SUDS 0.870），训练时间 26h（SUDS 64h，↓59%），推理时间 1.61s（SUDS 12.86s，↓87%）。

**VKITTI2 图像重建**（Table 2，SUDS* 为复现结果）：PSNR=30.894（SUDS* 30.853），SSIM=0.932（0.928），训练时间 26h（64h），推理时间 1.35s（11.89s）。

**NVS 实验**（Table 3）：在 75%/50%/25% 三档训练视图比例下，KITTI 和 VKITTI2 上 PaReNeRF 均取得最优 PSNR/SSIM/LPIPS，且在低视图密度下 SUDS 产生 ghosting 伪影而 PaReNeRF 保持清晰。

**消融实验**（Table 4）：Patch 采样单独使用可降低训练时间但推理时间不变且质量下降；Encoder-Decoder 单独使用推理提速但训练时间反而增加；参考解码器引入后即使 125K 迭代也显著优于 SUDS（PSNR 32.64 vs 28.31）。完整方案（Patch 采样+Encoder-Decoder+Reference Decoder，125K 迭代）达到最佳综合效果。

## 相关工作脉络
- **SUDS [48]**：当前大规模动态场景 SOTA，将场景分解为静态/动态/远场三部分并联合优化多种损失；本文在其基础上进行加速与质量改进，SUDS 采用 HR 随机采样导致训练/推理均慢。
- **UniSim [60]**：采用低分辨率特征图+CNN 上采样以加速训练和推理，但重建精度明显下降；本文在同样低分辨率思路下额外引入参考解码器弥补精度损失。
- **NeRF-SR [49]**：利用单个 HR 参考图通过 patch 匹配做 refine，但只能提升渲染质量而不能加速推理，且依赖深度图仅适用于静态场景。
- **pixelNeRF [61] / MVSNeRF [4]**：将参考视图特征经投影插值注入 NeRF 网络，仅适用于小尺度静态/物体中心场景，无法处理自动驾驶数据的稀疏单轨迹动态场景。
- **NSG [32] / PNF [22]**：分解场景为背景+多个独立 MLP 对象，内存随对象数线性增长，且需要 3D bounding box 和全景标签监督；本文不依赖额外标注，利用已有的光流和深度信号。
- **Block-NeRF [44] / Mega-NeRF [47]**：空间分区训练静态 NeRF；仅适用于静态场景，在动态场景下会产生模糊和伪影。

## 局限性与未来方向
- **尚未达到真正实时**：尽管训练和推理时间大幅降低，但作者明确指出"在构建真正实时的训练和渲染系统之前仍有诸多挑战"。
- **Patch 采样不影响推理速度**：推理阶段仍需逐像素采样整图，patch 采样的加速仅体现在训练数据加载环节。
- **仅验证了两个数据集**：主要在 KITTI 和 VKITTI2 上评估，未在其他大规模动态数据集（如 nuScenes、Waymo）上验证泛化性。
- **参考搜索的复杂度**：虽然光流缩小了搜索区域，但在大范围动态场景中，已知视角覆盖不足时参考信息质量可能下降。
- **未来方向**：可探索更高效的参考搜索策略、真正实现端到端实时训练+渲染、扩展到更大规模城市级动态场景。

## 研究启发与可借鉴点
- **Patch 采样思路可迁移**：将光线采样改为 patch 级采样以减少数据加载开销，这一思路可推广到其他 NeRF 变体（如 Instant NGP、3D Gaussian Splatting）的训练加速中。
- **参考信息融合机制可复用**：参考解码器中 CARN 级联残差网络与 PixelShuffle 上采样的组合，可作为通用的超分模块集成到其他神经渲染管线中。
- **光流辅助搜索可借鉴**：利用预计算光流缩小 patch 匹配搜索空间的方法，可迁移至视频级 NeRF 或动态场景稀疏输入重建任务中。
- **低分辨率渲染+高质量上采样是可行范式**：与 UniSim 纯 CNN 上采样相比，引入外部参考信息的混合上采样策略在精度-速度权衡上更具优势，可在更多神经渲染任务中验证该设计。
- **多损失联合优化的兼容性**：本文在 SUDS 全部损失基础上仅替换光度损失目标，说明参考解码器可与复杂的几何/运动正则化损失良好兼容，为后续方法扩展提供了模板。

## 关键术语表
- **NeRF（Neural Radiance Field）**：用 MLP 将 3D 坐标和视角映射为体积密度和颜色的隐式神经表示，用于新视图合成。
- **SUDS（Scalable Urban Dynamic Scenes）**：将城市动态场景分解为静态/动态/远场三个 hash table 分支的 NeRF 方法，本文的基线。
- **Patch Sampling**：以固定大小的图像块为单位进行光线采样，减少数据读取次数从而加速训练。
- **Optical Flow（光流）**：视频中相邻帧间像素的 2D 位移场，用于在本工作中预测前后视图中相似区域的位置。
- **Structural Similarity（SSIM）**：衡量两幅图像结构相似度的指标，在本工作中用于量化参考 patch 与目标 patch 的匹配程度。
- **Reference Decoder**：基于 CARN 的轻量级网络，将已知视角的高分辨率参考图像特征融合到低分辨率体渲染特征图的上采样解码过程中。
- **Novel View Synthesis（NVS）**：从少量已知视角重建 3D 场景并渲染全新视角图像的任务。
- **CARN（Cascading Residual Network）**：一种轻量级超分网络，通过局部和全局级联残差模块整合多尺度特征。
