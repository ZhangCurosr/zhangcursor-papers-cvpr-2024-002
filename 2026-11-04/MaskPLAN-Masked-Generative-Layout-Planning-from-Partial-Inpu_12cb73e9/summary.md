# 论文速读：MaskPLAN-Masked-Generative-Layout-Planning-from-Partial-Inpu

## 一句话总结
本文提出 MaskPLAN，一种基于图结构动态掩码自编码器（GDMAE）的生成模型，首次支持从任意比例的用户部分输入出发，通过五类属性联合自回归生成与交叉注意力校准，实现高保真、可迭代的室内户型图规划。

## 研究问题与动机
- 现有生成式布局方法多为端到端黑盒架构，忽略了建筑/室内设计中“边看边改”的迭代探索习惯。
- 现有用户引导方法无法接受任意范围的部分输入，难以从残缺的设计构思中自动补全完整布局。
- 属性支持不完整，多数方法仅能调整房间类型或边界框，无法同步控制邻接关系、面积与显式几何形状。
- 各属性间存在强相互依赖，但当前方法多采用分阶段序列化预测，未建立跨属性的联合学习与动态校准机制。

## 核心贡献（创新点）
1. **动态掩码生成框架（GDMAE）**：首次将 50%–100% 均匀随机动态掩码引入布局生成，使模型能无缝适配任意稀疏度的用户部分输入。
2. **五类全属性联合预测**：同步建模房间类型(T)、中心位置(C)、邻接关系(A)、面积(S)与显式形状区域(R)，打破以往仅输出包围盒或单一属性序列的限制。
3. **部分输入作为全局条件先验**：将用户已定义的属性与场地边界共同注入所有生成器，确保每一中间阶段的合成结果均贴合实际可行性。
4. **显式几何表征替代隐式后处理**：直接在像素级生成房间形状图像并通过预训练 ADLM 解码，显著提升布局几何精度与拓扑合理性。

## 方法详解
- **布局表示**：场地条件 $B$ 编码为三通道图像（入口、边界、内部掩码）；属性集 $L=\{T, C, A, S, R\}$ 中，$T$ 为 10 维类型整数序列，$A$ 为 $10\times8$ 二值邻接矩阵，$C/S/R$ 分别编码为房间中心点、面积色块、精确形状的高分辨率图像。
- **ADLM 预编码**：使用基于 VQ-VAE 的 Attribute Discrete Latent Model 将高分辨率 $C/S/R$ 图像压缩为离散视觉 token（维度 $V=64$），降低后续 Transformer 的计算压力。
- **GDMAE 架构**：包含一个部分输入编码器 $\mathcal{E}_U$ 与五个条件生成器 $\mathcal{G}_T, \mathcal{G}_C, \mathcal{G}_A, \mathcal{G}_S, \mathcal{G}_R$。生成过程分为图模块（预测 $T,C,A$）与几何模块（预测 $S,R$）两阶段自回归执行。
- **动态掩码策略**：训练时对 token 序列施加 50%–100% 均匀随机掩码并补零，推理时允许任意比例属性被冻结/输入，模型自动补全缺失项。
- **交叉注意力校准**：除首个 $\mathcal{G}_T$ 外，后续每个生成器编码器均对已预测序列与部分输入 $U$ 计算 cross-attention，实现阶段间信息传递与误差补偿。
- **损失函数**：分类损失 $\mathcal{L}_{cla}$ 对所有属性 token 预测使用分类交叉熵；重建损失 $\mathcal{L}_{rec}=2\mathcal{L}_{C_{img}}+1\mathcal{L}_{S_{img}}+2\mathcal{L}_{R_{img}}$ 在 ADLM 解码后的像素空间计算 L2 距离，强化几何细节保真。

## 实验与结果
- **数据集**：RPLAN（8万余张亚洲真实住宅户型图，80%/10%/10%划分）。
- **基线方法**：RPLAN, HouseDiffusion, iPLAN, iPLAN*, Graph2plan。
- **评估指标**：渲染图 FID ($fid_{img}$)、类型/邻接/面积向量 MSE ($mse_T, mse_A, mse_S$)。
- **主要结果**：Our III（输入完整布局图 $G$）全面领先，$fid_{img}=0.139$，$mse_T=0.00001$，$mse_A=1.947$，$mse_S=0.442$；Our II（仅 25% 随机部分输入）仍显著优于多数基线（$fid_{img}=1.741$，$mse_T=0.00492$）。HouseDiffusion 因缺失边界条件 $B$ 导致整体偏弱；Graph2plan 与 iPLAN 因未充分学习属性间依赖，MSE 偏高。
- **消融结论**：去除程序化条件预测使 $fid_{img}$ 恶化至 23.103；替换 VQ-VAE 为普通 VAE 升至 39.272；去除逐像素重建损失升至 14.092；静态掩码（0%-100% 或 25%-100%）均劣于本文的 50%-100% 动态掩码（4.182）。

## 相关工作脉络
- **Generative Floorplan Layout Synthesis**：早期工作（LayoutGAN, HouseGAN）将布局视为栅格图像生成，缺乏显式空间关系建模；后期 Graph2plan、HouseDiffusion 引入图结构，本文在此基础上进一步支持多模态属性联合预测与部分输入驱动。
- **User-guided Generative Modeling**：RPLAN、iPLAN 等多采用固定序列预测或仅支持边界框后处理，无法自由增删改任意属性；本文通过动态掩码实现真正灵活的交互定制。
- **Graph-structured Masked Autoencoders**：受 MAE 与 GMAE（如 MolGAN、GraphMAE）启发，将掩码重建思想从分子/节点图迁移至多属性布局图，并创新性地引入属性间自回归条件生成。
- **定位差异**：相比纯端到端生成或仅支持单一属性条件的方法，MaskPLAN 是首个同时支持“任意比例部分输入 + 五类全属性联合预测 + 跨属性校准”的户型生成模型。

## 局限性与未来方向
- 训练数据限制：仅支持最多 8 个房间且墙体强制正交，难以直接泛化至复杂户型或真实建筑规范。
- 未在新颖/大规模数据集（如 SwissDwellings）上验证，跨地域建筑风格的泛化能力待考察。
- 当前仅聚焦单层平面布局，未来可拓展至多层/复杂楼层拓扑的生成规划。

## 研究启发与可借鉴点
- **动态掩码适配部分条件生成**：将固定比例掩码改为训练时 50%-100% 随机掩码，可无缝兼容推理阶段任意稀疏度的用户条件，适合其他“残缺条件补全”任务。
- **VQ-VAE 离散视觉 Token 降维**：用预训练 ADLM 将高分辨率布局图像压缩为离散 token，既保留几何细节又大幅降低 Transformer 计算开销，可在图像/地图生成中复用。
- **跨属性自回归校准机制**：后续生成器对前期预测结果做交叉注意力而非简单拼接，能有效缓解误差累积；适用于多步骤、强耦合的属性预测任务。
- **交互式工作流设计**：支持 Add/Edit/Remove/Freeze 属性的迭代操作，为 CAD/BIM 与 AIG
